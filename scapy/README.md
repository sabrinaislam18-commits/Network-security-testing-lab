# Scapy Network Security Labs

Hands-on Python and Scapy exercises completed in an isolated cybersecurity lab environment.

## Activities

- Telnet packet sniffing
- ICMP packet sniffing
- ICMP packet spoofing
- TCP reset testing
- TCP session hijacking concepts
- Packet header analysis
- Wireshark verification

## Tools

- Python
- Scapy
- Wireshark
- Docker
- SEED Ubuntu Linux

## Environment

All demonstrations were performed in an authorised and isolated educational lab environment.
